      Tutorial

      Starting a session

      In web mode, each device or person gets their own session -- pick + New Session from the session list (optionally starting from a saved playlist instead of the whole library), or Select a session already running to jump back into it. Picking a Genre and Era starts playback immediately -- there's no separate confirm step, and changing either one at any time (even mid-song) re-shuffles and starts playing that combination right away.

      Launching the player, casting, and AirPlay

      The genre/era screen is the remote control, not the video itself -- press Launch Player to open the actual video in a browser tab. That tab is a normal web page playing a normal video, so your browser/OS's own casting controls work on it directly: AirPlay in Safari, or Chrome's Cast menu, will send that tab straight to a TV or speaker. If you'd rather not cast, you can instead open the player link directly on whatever device is connected to the TV -- see "Connecting remotely" below.

      DJ Request

      Press DJ Request to browse every song in the current genre/era, sorted by artist, with a Queue button on each row. Queueing a track plays it next without disturbing the rest of the shuffle order -- the currently-playing and queued rows are highlighted, and the "Up next" line always shows what's coming, whether that's your queued pick or just a preview of the next shuffled track.

      Managing tracks

      Open Settings > Tracks to add, edit, or delete songs one at a time -- the add/edit form has a Search YouTube button that looks up a song and fills in its URL for you to preview before saving. For bulk changes, use Export CSV to download the whole library as a spreadsheet, and Import CSV to bring one back in, either appending to the current library or replacing it entirely. Check off rows and use Delete selected to bulk-delete.

      Cache warming

      Spin Cycle downloads each video once and plays the local copy every time after, so a party doesn't depend on live internet/YouTube access. Warm cache (in Settings) walks the whole library and downloads anything missing ahead of time -- it also runs automatically in the background on startup. While it's running, the Cache column in the Tracks table updates live, track by track, so you can watch progress and see which songs failed (hover a failure for the error).

      Playlists

      Open Settings > Playlists to build a named, curated subset of the library -- filter by genre/era, check off the songs you want, and save. A saved playlist shows up as an option when starting a new session, scoping that session's genre/era dials and shuffle to just those tracks. Editing or deleting a playlist later doesn't affect a session already running from it.

      Overlays

      Open Settings > Overlays to create a logo + phrase banner (e.g. "Intermission...") shown across the top of the player -- useful for branding a party or marking a break. Only one overlay can be active at a time; activate/deactivate it from the overlay list.

      YouTube sign-in cookies

      Occasionally YouTube blocks a specific video with a "Please sign in to confirm you're not a bot" error. In Settings > YouTube sign-in cookies, pick the browser you're already logged into YouTube with on this machine -- Spin Cycle will read that browser's cookies when downloading, exactly as if the request came from your own signed-in tab. Leave it set to "None" if you haven't hit that error.

      Connecting remotely (phone or player)

      Settings > Deployment info lists a Remote control link -- open it on a phone (or any device on the same network) to get the same session list and controls, so one device can start a session and cast to the TV while another acts as the controller. It also lists a Player link for every currently-running session, for when a device can't cast -- open that link directly on a smart TV's browser, or on whatever's plugged into the TV, instead of using Launch Player + casting.

      A few other things

      Skip/Stop control playback without re-tuning the genre/era. Multiple sessions can run at once, each fully independent (its own genre/era, queue, and player) -- close one from the session list when you're done with it. Playback log (in Settings) is a running record of every play/skip/cache-miss, useful for troubleshooting. Deployment info also shows the app version and a link to the GitHub Releases page for updates.
